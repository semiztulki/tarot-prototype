# Arcana · Tarot prototype

Рабочий прототип международного сервиса Таро. **Arcana — предварительное название**, а не утверждённый бренд.

## Что работает

- Полный интерфейс и базовые трактовки на русском и английском. Переключение языка сохраняет карты и их положение.
- Одна карта и три карты «прошлое — настоящее — будущее».
- Бесплатная демонстрация расширенных раскладов на 5 и 6 карт, без оплаты и регистрации.
- 78 карт; прямое и перевёрнутое положение; темы «общий вопрос», «отношения», «работа», «учёба», «выбор»; намерение вопроса и роль позиции.
- Физическая колода: поиск и ручной ввод карт, выбор положения, проверка повторов. В первой версии поддерживается система Rider–Waite–Smith.
- Дневник в текущем браузере: сохранение, заметки, повторное открытие, удаление с отменой, экспорт JSON и текст отдельного расклада.
- Справочник 78 карт с поиском на обоих языках и фильтром по масти.
- Адаптивная вёрстка, клавиатурная навигация, учёт уменьшенного движения.

## Запуск

Внешних зависимостей и сборки нет. Нужен любой статический HTTP-сервер.

```bash
python3 -m http.server 4173 --directory docs
```

Откройте `http://localhost:4173`. Для интерфейса можно задать `?lang=ru` или `?lang=en`. На другом устройстве требуется HTTPS для Web Crypto.

Тестирование (Node.js 22 или новее):

```bash
npm test
```

## GitHub Pages

В настройках репозитория: **Settings → Pages → Deploy from a branch → main → /docs → Save**. Файл `docs/.nojekyll` отключает обработку Jekyll. Все пути относительные, поэтому проект работает в подпапке репозитория без перенастройки.

GitHub Pages используется для бесплатного демонстрационного прототипа. Коммерческую версию, платежи и серверные функции следует размещать отдельно с учётом [правил GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits).

## Границы этой версии

Это интерактивный прототип, а не готовый платный сервис. Интерпретации — **оригинальный редакционный черновик**, требующий проверки специалистом перед коммерческим выпуском. Тематическая логика для старших арканов использует отдельные блоки по карте и теме; для младших — базовый текст карты и тематический слой масти. Специальные сочетания покрывают шесть пар прямых старших арканов; остальные используют структурную трактовку. Полной редакционной базы из проектного плана пока нет.

Изображения — оригинальные геометрические эскизы, а не иллюстрации Уэйта — Смит. Фотораспознавание, другие традиции колод, руны, лунный календарь, камни, турецкий и испанский языки отложены.

Генеративный ИИ во время работы приложения не используется. Нет API-ключей, аналитики, аккаунтов, серверной базы, платежей и внешних шрифтов. Введённый текст не анализируется для выбора темы: пользователь выбирает её явно. Данные не отправляются приложением на сервер; обычные технические запросы загрузки сайта обрабатывает хостинг GitHub Pages.

Дневник хранится незашифрованным в `localStorage` этого браузера, доступен людям с доступом к устройству и удаляется при очистке данных браузера. Экспорт JSON — резервная копия; обратный импорт в интерфейсе пока не реализован. Лимит — 100 записей. При обновлении содержания запись сохраняет карты и номер редакции, а трактовка строится текущей версией текстов; архивирование исходных текстов относится к серверному этапу.

Перед платным пилотом: завершить и проверить тематическую базу, хранить версии исходных трактовок, добавить серверные аккаунты и приватный дневник, выбранный эквайринг, возрастные сценарии и юридические тексты под компанию и рынки.

## Права

Код, тексты и SVG подготовлены для владельца проекта. Публичная доступность репозитория не означает предоставления лицензии на коммерческое использование. Сторонние колоды и их руководства не копируются.
